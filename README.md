# AI Quant Trading & Statistical Arbitrage Engine

This is our C++17 object-oriented programming course project at VIT Pune.

The program downloads hourly BTCUSDT and ETHUSDT candles from Binance. It chooses settings for each strategy on the older 70% of the data and tests that choice on the newer 30%. It then prints a report that compares each strategy with buy-and-hold. It can also show the current signal from fresh candles. It uses public data only and never places a trade.

## How to build

You need Windows with MSYS2 UCRT64, with g++, cmake, ninja and libcurl installed. From the project folder, run:

```
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build -j2
build/quant_tests.exe
```

The last command runs the tests. The build copies the DLLs it needs next to the program.

## How to run

Double-click `run_advisor.bat`, or run `build/quant_advisor.exe`. This opens the menu:

```
1) Download / update data     4) Recommend strategies (train/test)
2) Show data summary          5) Live signals
3) Backtest one strategy      6) OOP concepts demo
0) Exit
```

Run option 1 first to download the data, and option 4 before option 5. The report is generated by the program and saved in `reports/recommendation.txt`.

The same actions work as command-line options: `--download`, `--summary`, `--recommend`, `--live`, `--demo` and `--help`. The `--demo` option runs the concepts demo, which prints one labelled line for each syllabus example.

## Project structure

- `src/candle.*`, `errors.hpp`, `indicators.hpp`: the basic types and the indicators
- `src/datastore.*`, `fetcher.*`, `klines.cpp`, `ratio.*`: the data
- `src/strategy.*`, `strategies.cpp`, `knn.cpp`: the Strategy class and its four children
- `src/backtester.*`: the trading loop and the metrics
- `src/advisor.*`, `report.cpp`: the train and test split, the verdicts and the report
- `src/commands.*`, `live.cpp`, `main.cpp`: the menu and the options
- `src/demo/`: small examples of syllabus topics, kept apart from the main program
- `tests/`: the tests
- `docs/SYLLABUS_MAP.md`: where each syllabus topic appears in the code

## Limits

- The "AI" is a small k-nearest-neighbours model plus choosing settings on the training data. It is not deep learning.
- The arbitrage is a long-only mean-reversion signal on the ETH/BTC price ratio. It is not true two-leg trading.
- There is one 70/30 split, with about 7 months of test data, so the results are weak evidence.
- Trades fill at the next open with a flat cost, and there is no market impact.
- The results are for research only and are not financial advice.
